# Mi Galería Web

Aplicación web desarrollada con JavaScript que consume la API RESTCountries para obtener y mostrar información de diferentes países.

## Demo

🔗 [Ver aplicación](https://bella-marin.github.io/mi-galeria-web/)

## Descripción

Este proyecto consiste en una aplicación web que obtiene información de países mediante una API externa y la presenta de forma visual e interactiva.

El proyecto fue desarrollado como práctica de consumo de APIs REST y desarrollo frontend con JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- RESTCountries API
- Git
- GitHub Pages

## API utilizada

El proyecto utiliza **RESTCountries API** para obtener información sobre diferentes países.

Los datos son consultados desde una API externa y posteriormente procesados y mostrados en la interfaz web.

## Objetivos del proyecto

- Practicar el consumo de APIs REST.
- Trabajar con solicitudes HTTP desde JavaScript.
- Manipular y mostrar datos obtenidos desde una API.
- Desarrollar una interfaz web utilizando HTML, CSS y JavaScript.
- Publicar una aplicación web utilizando GitHub Pages.
